# 日本語教育史

日本語を外国人・非母語話者に教えてきた歴史を扱う。時代ごとに、誰に・何のために日本語を教えたかが変化してきた。試験では、時代区分・代表的な人物や機関・当時の目的を押さえることが重要。

## 大きな時代の流れ

```
近世以前（宣教師など）→ 明治〜戦前（近代化・植民地）→ 戦中（大東亜共栄圏）
　→ 戦後（留学生・国際交流）→ 現代（生活者・就労者・多様化）
```

## 時代ごとの概要

|時代|概要|
|-|-|
|近世以前|キリスト教の宣教師（ロドリゲスら）が布教のために日本語を学び、文法書・辞書などを残した|
|明治〜大正|近代化の中で、来日する外国人や、日本が関わる地域での日本語教育が始まる|
|戦前・戦中|植民地・占領地（朝鮮・台湾・南洋など）で、国策として日本語（「国語」）教育が行われた。大東亜共栄圏の理念と結びつく|
|戦後|留学生の受け入れ、国際交流の広がりとともに、日本語教育が再編・拡大|
|現代|生活者としての外国人、技能実習・特定技能などの就労者、児童生徒、海外の学習者など対象が多様化|

## 戦前・戦中の日本語教育（注意点）

- 植民地・占領地での日本語教育は、**国策・同化政策**と強く結びついていた。日本語を「国語」として広め、現地の言語・文化を抑える側面があった。
- この歴史は、言語教育が政治・支配と結びつきうることを示す例として重要。

## 戦後〜現代の展開

- **留学生受け入れ**の拡大（留学生10万人計画・30万人計画などの政策）。
- **国際交流基金**（海外の日本語教育支援）、**日本語教育の各種試験**の整備。
- **生活者・就労者への日本語教育**の重要性の高まり（在留外国人の増加）。
- **登録日本語教員**の国家資格化（2024年）など、担い手の制度整備（詳細は項目07）。

## まぎらわしい区別

- **戦前・戦中の日本語教育** ↔ **現代の日本語教育**：国策・同化政策と結びついた「国語」教育（戦前・戦中）か、多様な対象への支援・国際交流（現代）か。目的が大きく異なる。
- **宣教師による日本語学習（近世以前）** ↔ **近代以降の日本語教育**：布教のための語学（宣教師）か、近代化・国策・国際交流を背景とする教育（近代以降）か。
- **国際交流基金** ↔ **出入国在留管理庁**：海外の日本語教育支援（国際交流基金）か、在留管理（出入国在留管理庁）か。
