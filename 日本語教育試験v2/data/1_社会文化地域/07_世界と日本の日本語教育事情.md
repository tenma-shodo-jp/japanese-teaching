# 世界と日本の日本語教育事情（日本語教育人材）

日本語教育を支える人材（担い手）の役割分担と、その養成・研修・資格を扱う。文化庁の「日本語教育人材の養成・研修の在り方について（報告）」（2018／2019改定）が土台で、人材を**役割**（教師・コーディネーター・支援者）と**キャリアの段階**（養成・初任・中堅）で整理している。

## 3つの役割区分

|人材|主な役割|資格|
|-|-|-|
|**日本語教師**|専門的に日本語を教える|認定日本語教育機関で教えるには国家資格**「登録日本語教員」**が必要（2024年4月〜）|
|**日本語教育コーディネーター**|日本語教育プログラムの企画・運営、教師・支援者・関係機関をつなぐ調整・まとめ役|国家資格はない。文化庁・文科省などの**研修**で育成|
|**日本語学習支援者**|教師のもとで、学習者に寄り添って学習を支援する|国家資格はない。**研修**で養成。**ボランティア**が担うことが多い|

```
コーディネーター（企画・調整・まとめ役）
　├─ 日本語教師（専門的に「教える」）※登録日本語教員は国家資格
　└─ 学習支援者（教師のもとで学習者に寄り添う。ボランティア中心）
```

- **重要**：国家資格があるのは**日本語教師（登録日本語教員）だけ**。コーディネーター・支援者は「資格」ではなく、文化庁の枠組み上の**役割区分**で、研修によって育成される。

## キャリアの段階（教師の場合）

日本語教師は、役割だけでなく成長段階でも分けられる。

|段階|説明|
|-|-|
|養成|これから教師になるために学ぶ段階（養成講座・大学の課程など）|
|初任|教え始めの段階|
|中堅|経験を積み、後進の指導や研修にも関わる段階|

- コーディネーター・支援者にも、それぞれ養成・研修の枠組みが設けられている。

## 登録日本語教員（国家資格）

- **2024年4月**、「**日本語教育機関認定法**」の施行に伴って新設された国家資格。
- それまで日本語教師は**民間資格しかなかった**が、国家資格化された。
- **認定日本語教育機関**（国が認定した機関）で日本語を教えるには、この資格が必要。
- 取得には、試験（基礎試験・応用試験）と教育実習などが関わる。既存の教師には**経過措置**が設けられている。

## 活動分野の広がり

日本語教育人材が活動する分野は多岐にわたる。

- **生活者としての外国人**（地域の日本語教室など）
- **留学生**（大学・日本語学校など）
- **就労者**（技能実習・特定技能・育成就労などの受け入れに伴う日本語支援 → 項目02）
- **児童生徒等**（学校での日本語指導が必要な子ども）
- **難民等**、**海外の学習者**

- 地域の日本語教育では、コーディネーターが体制を設計し、教師と学習支援者（ボランティア）が連携して支える形が一般的。

## 日本語教育に関わる主な機関

日本語教育・外国人支援に関わる機関は、目的によって役割が分かれる。英略称と「何をする機関か」をセットで押さえる。

|機関|正式名称（日本語）|法人の性格|中心的な役割|
|-|-|-|-|
|**JASSO**|日本学生支援機構|独立行政法人（公的）|留学生・学生支援、奨学金、**EJU（日本留学試験）**の実施|
|**JF**|国際交流基金|独立行政法人（公的）|海外の日本語教育支援・国際文化交流、**JLPT・JFT-Basic・JFスタンダード**、『まるごと』『いろどり』|
|**JEES**|日本国際教育支援協会|公益財団法人|**国内のJLPT実施**、**日本語教育能力検定試験**、留学生支援|
|**AOTS**|海外産業人材育成協会|一般財団法人（民間）|海外の**産業人材・企業人材**の技術・経営・日本語研修|
|**JITCO**|国際人材協力機構|公益財団法人（民間）|**技能実習・特定技能**の受け入れ支援・相談・情報提供|
|**OTIT**|外国人技能実習機構|認可法人（公的）|**技能実習計画の認定・実地検査・実習生保護**|
|**NINJAL**|国立国語研究所|研究機関|日本語・日本語教育の研究、**コーパス・分類語彙表**などの言語資源|
|**AJALT**|国際日本語普及協会|公益社団法人|日本語教育の実践・教材開発（『**Japanese for Busy People**』）|

### 試験・教材との対応（頻出）

- **EJU（日本留学試験）** → JASSO
- **JLPT** → JF（海外）＋JEES（国内）の共同実施
- **JFT-Basic**、**JFスタンダード** → JF
- **日本語教育能力検定試験** → JEES（民間検定）
- **日本語教員試験 / 登録日本語教員** → 国の国家資格制度（文部科学省所管）

### まぎらわしい機関の区別

- **AOTS** ↔ **JITCO**：産業人材を研修で育てる（AOTS）か、技能実習・特定技能の受け入れを支援する（JITCO）か。
- **JITCO** ↔ **OTIT**：受け入れ支援・相談（JITCO）か、計画の認定・検査・実習生保護という監督（OTIT）か。
- **JASSO** ↔ **JEES**：EJUや留学生支援（JASSO）か、国内のJLPT・日本語教育能力検定試験（JEES）か。
- **JF** ↔ **JEES**：JLPTは共同実施だが、海外中心がJF、国内中心がJEES。

## まぎらわしい区別

- **日本語教師** ↔ **学習支援者**：専門的に教える専門家（教師）か、教師のもとで学習者に寄り添って支援する立場（支援者・ボランティア中心）か。
- **コーディネーター** ↔ **教師**：プログラムの企画・調整・連携を担う（コーディネーター）か、実際に教える（教師）か。
- **登録日本語教員（国家資格）** ↔ **コーディネーター・支援者（資格ではない役割）**：国家資格があるのは教師のみ。他の2つは研修で育成される役割区分。
- **役割区分（教師・コーディネーター・支援者）** ↔ **キャリア段階（養成・初任・中堅）**：何をする人かの分類と、どの成長段階かの分類で、切り口が異なる。
