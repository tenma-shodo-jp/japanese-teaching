# 教授法とは

外国語（第二言語）を教えるための、理論に基づいた指導の方法・体系のこと。時代ごとの言語観（言語とは何か）・学習観（どう学ぶか）を反映して発展してきた。試験では、**提唱者・特徴・背景理論（言語学／心理学）・練習方法**をセットで押さえることが重要。

## 大きな流れ（歴史）

```
文法訳読法 → 直接法（オーラル・メソッド） → オーディオリンガル・メソッド
　→ 認知主義・人間中心の教授法（サイレントウェイ等） → コミュニカティブ・アプローチ
　→ タスク中心・内容重視（TBLT／CLIL）
```

- **母語を使う → 使わない**（訳読法 → 直接法）
- **形式（文法・構造）重視 → 意味・伝達重視**（オーディオリンガル → コミュニカティブ）という流れが大きな軸。

## 代表的な教授法一覧（年代順）

|時代（目安）|教授法|提唱者・代表|特徴|背景理論|
|-|-|-|-|-|
|19世紀以前〜|文法訳読法（Grammar-Translation Method）|伝統的手法|文法規則を学び、母語と目標言語を相互に翻訳。読み書き中心|—（伝統的な古典語教育）|
|19世紀末〜20世紀初|直接法（Direct Method）|ベルリッツ ほか|母語を介さず、目標言語だけで教える。実物・絵・動作で意味を示す|—|
|19世紀末〜20世紀初|ナチュラル・メソッド|—|母語を使わず自然に習得させる考え方（直接法系の総称）|—|
|1920〜30年代|オーラル・メソッド（Oral Method）|H. パーマー|口頭練習を重視。日本の英語教育にも影響。段階的な口頭導入|—|
|1940年代（第二次大戦中）|アーミー・メソッド（ASTP）|米軍|短期集中・少人数。会話と聴解を徹底反復|構造言語学|
|1950〜60年代|オーディオリンガル・メソッド（Audio-Lingual Method）|C. フリーズ ほか|**ミムメム練習**（模倣・記憶）と**パターン・プラクティス**（文型練習）。間違いを避け習慣形成|構造言語学＋行動主義心理学|
|1960年代|認知（コード）学習理論|チョムスキーの影響|規則を理解し創造的に運用する。丸暗記より理解を重視|生成文法・認知心理学|
|1960年代〜|サイレントウェイ（Silent Way）|C. ガテーニョ|教師は極力**沈黙**し、学習者の自己発見・自己修正を促す。ロッド（色棒）・フィデル（発音表）を使う|認知主義・学習者中心|
|1960〜70年代|サジェストペディア（Suggestopedia）|G. ロザノフ|**暗示**の力で心理的な壁を取り除く。音楽・リラックス環境で不安を下げ記憶を促進|暗示学・心理学|
|1960〜70年代|TPR（全身反応教授法）|J. アッシャー|教師の指示に**体を動かして反応**。聞くこと（理解）を先行させ、発話を強制しない|第一言語習得の観察|
|1970年代|CLL（コミュニティ・ランゲージ・ラーニング）|C. カラン|学習者を仲間（コミュニティ）とみなす。カウンセリング的に不安を軽減し、学習者主導で発話|人間性心理学・カウンセリング|
|1970年代〜|コミュニカティブ・アプローチ（CLT）|ハイムズ「伝達能力」ほか|文法の正確さより**伝達能力**を育成。場面・機能・タスク重視。現在の主流|社会言語学・伝達能力（communicative competence）|
|1970年代末〜1980年代初|ナチュラル・アプローチ|S. クラッシェン／T. テレル|理解可能なインプット（i+1）重視。不安（情意フィルター）を下げる。習得と学習を区別|クラッシェンのインプット仮説|
|1980年代〜|タスク中心の教授法（TBLT）|N. プラブ ほか|意味のある**タスク（課題）**の遂行を通じて言語を学ぶ|コミュニカティブ・アプローチの発展|
|1980〜90年代〜|内容重視（CBI／CLIL）|—|教科・テーマなどの**内容**を学びながら同時に言語も学ぶ|—|

※年代はあくまで目安。特に人間中心の教授法（サイレントウェイ／サジェストペディア／CLL／TPR／ナチュラル・アプローチ）はほぼ同時期に別々に生まれたもので、厳密な前後関係よりも「同じ1960〜70年代のグループ」として押さえるとよい。

## 文型練習（パターン・プラクティス）の種類

**パターン・プラクティス（文型練習）**は、オーディオリンガル・メソッドで体系化された口頭ドリル。文型を反復して定着させることを目的とし、次のような種類がある。

|練習の種類|内容|例|
|-|-|-|
|反復練習（repetition drill）|教師の言った文をそのまま繰り返す|「本を読みます」→「本を読みます」|
|代入練習（substitution drill）|文の一部を、与えられた語（キュー）に入れ替える|「本を読みます」→（新聞）→「新聞を読みます」|
|変形練習（transformation drill）|文の形を変える（肯定↔否定、現在↔過去、能動↔受身など）|「読みます」→「読みません」|
|拡大練習（expansion drill）|文に語句を付け足して、だんだん長く・複雑にしていく|「読みます」→「本を読みます」→「図書館で本を読みます」|
|結合練習（combination drill）|2つの文を1つにつなげる|「雨が降りました／試合が中止になりました」→「雨が降ったので、試合が中止になりました」|
|応答練習（question-answer drill）|質問に対して決まった形で答える|「何を読みますか」→「本を読みます」|
|完成練習（completion drill）|文の欠けた部分を埋めて完成させる|「毎日 日本語を___。」→「勉強します」|

- 練習は、意味を考えず形だけ操作する**機械的ドリル** → 意味を意識する**有意味ドリル** → 自分の内容を言う**コミュニカティブな練習**、へと段階づけると効果的とされる。
- パターン・プラクティスは形式の定着に役立つ一方、機械的な反復だけでは実際の場面で意味を伝える力が育ちにくい、という批判がコミュニカティブ・アプローチにつながった。

## 押さえておきたいポイント

- **オーディオリンガル・メソッド**は頻出。
  - 背景＝**構造言語学＋行動主義**、練習＝**ミムメム練習／パターン・プラクティス**、誤りは「悪い習慣」として避ける。
- **人間中心の教授法（1960〜70年代）**は「提唱者と特徴」の組み合わせがよく問われる。
  - サイレントウェイ＝**ガテーニョ／沈黙・ロッド**
  - サジェストペディア＝**ロザノフ／暗示・音楽**
  - CLL＝**カラン／カウンセリング**
  - TPR＝**アッシャー／全身反応・理解先行**
  - ナチュラル・アプローチ＝**クラッシェン／インプット・情意フィルター**
- **コミュニカティブ・アプローチ**は「伝達能力（ハイムズ）」がキーワード。文法の正確さ偏重への反省から生まれた。

## まぎらわしい区別

- **直接法** ↔ **オーディオリンガル・メソッド**：どちらも母語を避けるが、オーディオリンガルは「構造言語学＋行動主義」に基づく体系的な文型反復が特徴。
- **サイレントウェイ** ↔ **サジェストペディア**：前者は「教師が黙る・学習者の発見」、後者は「暗示・リラックス・音楽」。
- **習得（acquisition）** ↔ **学習（learning）**：クラッシェンの区別。ナチュラル・アプローチの前提。
