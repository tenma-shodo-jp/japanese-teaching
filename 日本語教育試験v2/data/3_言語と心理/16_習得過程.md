# 習得過程（第一言語・第二言語）

言語がどのように身についていくかを扱う。中心となるのは、学習者が触れた言語情報が取り込まれ、内在化し、使えるようになるまでの流れと、その過程で学習者が**規則（ルール）を自分で見つけ出していく**しくみである。

## 習得の流れ（インプット→インテイク→習得→アウトプット）

```
インプット（input）→ インテイク（intake）→ 習得（acquisition）→ アウトプット（output）
 触れた言語情報すべて  取り込まれた一部     内在化・定着       産出（話す・書く）
```

|用語|概要|ポイント|
|-|-|-|
|インプット（input）|学習者が聞いたり読んだりした言語情報の全体|触れた情報「すべて」|
|インテイク（intake）|インプットのうち、注意を向けて理解し、頭の中に取り込まれた部分|インプットより必ず小さい「一部」。習得につながる|
|習得（acquisition）|インテイクされたものが内在化し、使えるようになった状態|—|
|アウトプット（output）|取り込んだものを使って話す・書く産出活動|産出を通じてさらに習得が促されることもある|

- **ポイント**：触れた情報（インプット）が全部身につくわけではなく、その一部だけが**インテイク**として習得につながる。

## 習得に関わる主な仮説

|仮説|提唱者|概要|
|-|-|-|
|インプット仮説（i+1）|クラッシェン|今の力（i）より少し上（i+1）の**理解可能なインプット**が習得を進める。理解できることがインテイクの前提|
|情意フィルター仮説|クラッシェン|不安・緊張が高い（フィルターが高い）と、インプットが取り込まれにくくなる。不安を下げる環境が大切|
|気づき仮説（noticing hypothesis）|シュミット|インプットの中の言語形式に「**気づく**（noticing）」ことがインテイクの鍵。気づかれなければ取り込まれにくい|
|アウトプット仮説|スウェイン|産出（アウトプット）することで、自分に足りない点に気づき、習得が促される|

- クラッシェンは、無意識に自然に身につく「**習得（acquisition）**」と、意識的に規則を学ぶ「**学習（learning）**」を区別した（習得・学習仮説）。

## 規則（ルール）を探し出すしくみ

学習者は、与えられた例や場面から自分で規則を見つけ出し、試し、修正していく。

- **仮説検証（hypothesis testing）**：インプットから「こういう規則かな」と仮説を立て、使ってみて確かめ、フィードバックを受けて修正していく過程。
- **中間言語（interlanguage）**：この過程で学習者がつくり上げる、母語とも目標言語とも異なる独自の言語体系。習得が進むにつれて目標言語に近づく。
  - **化石化（fossilization）**：ある段階の誤りや不完全な形が、それ以上変化せず固定化してしまう現象。
- **帰納的学習** ↔ **演繹的学習**：
  - 帰納的学習…多くの例から自分で規則を発見する（＝「ルールを探し出す」）。
  - 演繹的学習…先に規則を教わってから例に当てはめる。
- 「文法規則を推測・分析する」ことは、学習ストラテジーでは**認知ストラテジー**（項目17）の例にあたる。

## 誤り（エラー）のとらえ方

- 行動主義（オーディオリンガル）では、誤りは「悪い習慣」として避けるべきものとされた。
- その後、中間言語研究では、誤りは学習者が**仮説検証をしている自然な過程の現れ**としてとらえ直された。習得の手がかりとして重視される。

## まぎらわしい区別

- **インプット** ↔ **インテイク**：触れた言語情報の全体（インプット）か、そのうち取り込まれた一部（インテイク）か。
- **インテイク** ↔ **習得**：取り込み（インテイク）の段階か、定着して使える（習得）段階か。
- **習得（acquisition）** ↔ **学習（learning）**：無意識・自然に身につく（習得）か、意識的に規則を学ぶ（学習）か。
- **帰納的学習** ↔ **演繹的学習**：例から規則を発見する（帰納）か、規則を先に教わって当てはめる（演繹）か。

## キーワードと人名

- **クラッシェン（Krashen）**：モニターモデル（習得・学習仮説、インプット仮説 i+1、情意フィルター仮説など）。
- **シュミット（Schmidt）**：気づき仮説（noticing hypothesis）。
- **スウェイン（Swain）**：アウトプット仮説。
- **中間言語 / 化石化**：セリンカー（Selinker）が中間言語の概念を提唱。
