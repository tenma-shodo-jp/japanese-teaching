# 記憶と言語学習

言語を学ぶことは、情報を覚え・保持し・使えるようにする過程でもある。ここでは言語学習に深く関わる**記憶（memory）**のしくみと分類を整理する。記憶は大きく、**保持時間**による分類（感覚記憶・短期記憶／作動記憶・長期記憶）と、長期記憶の**内容**による分類（宣言的記憶・手続き記憶など）に分けて捉える。

## 保持時間による分類

情報は「感覚記憶 → 短期記憶／作動記憶 → 長期記憶」の順に処理・保持される。

```
感覚記憶  →  短期記憶／作動記憶  →  長期記憶
 一瞬        数十秒・少量を保持＆処理     長期・大容量で保存
```

|名称|保持時間・容量|概要|
|-|-|-|
|感覚記憶|ごく短時間（一瞬）|見聞きした情報が感覚器官に一瞬だけ残る記憶。注意を向けたものが短期記憶へ送られる|
|短期記憶（short-term memory）|数十秒・少量|情報を短時間、一時的に「保持」する記憶。リハーサル（反復）しないと消える|
|作動記憶（ワーキングメモリ）|数十秒・少量|短期記憶を発展させた考え方。情報を保持しながら同時に「処理・操作」する。バドリー（Baddeley）のモデルが有名|
|長期記憶（long-term memory）|長期・大容量|情報を長く保存する記憶。容量はほぼ無制限とされる|

- **短期記憶 ↔ 作動記憶**：短期記憶は「保持」中心。作動記憶は「保持＋処理」まで含む（例：暗算する、聞いた文を理解しながら次を聞く）。
- **マジカルナンバー7±2**（ミラー, Miller）：短期記憶で一度に保持できるのはおよそ7項目前後という考え。関連語として、意味のまとまりにまとめる**チャンク化（chunking）**がある。

## 長期記憶の内容による分類

長期記憶は、ことばで説明できるかどうかで**宣言的記憶**と**非宣言的記憶（手続き記憶など）**に分かれる。

```
長期記憶
├─ 宣言的記憶（陳述記憶）＝ことばで説明できる「知識」
│    ├─ エピソード記憶 … 個人的な出来事・経験（いつ・どこで・何を）
│    └─ 意味記憶 … 一般的な知識・事実・語の意味
└─ 非宣言的記憶＝ことばにしにくい「体で覚えた技能」
     └─ 手続き記憶 … 技能・手順（自転車の乗り方、発音や運用のスキルなど）
```

|名称|概要|例|
|-|-|-|
|宣言的記憶（陳述記憶）|ことばで説明できる知識の記憶|「富士山は日本一高い山だ」と言える|
|エピソード記憶|「いつ・どこで・何が」という個人的な出来事・経験の記憶|去年の夏に友だちと海に行った／その単語を初めて習った授業を覚えている|
|意味記憶|一般的な知識・事実・語の意味の記憶（体験と切り離された知識）|"apple" は「りんご」という意味だと知っている|
|手続き記憶（非宣言的）|ことばにしにくい、体で覚えた技能・手順の記憶|自転車の乗り方／楽器の演奏／すらすら話す発音・運用のスキル|

## リハーサルの種類

**リハーサル（rehearsal）**とは、情報を頭の中で繰り返し扱って記憶にとどめようとする働き。大きく2種類あり、長期記憶への残りやすさが異なる。

|名称|概要|例|定着|
|-|-|-|-|
|維持リハーサル（maintenance rehearsal）|情報をただ繰り返して保持しようとする方法（浅い処理）|電話番号を口の中で何度も唱える|短期記憶にとどめるのに役立つが、長期記憶には残りにくい|
|精緻化リハーサル（elaborative rehearsal）|情報に意味づけをしたり、既有知識（すでに知っていること）と関連づけたりして覚える方法（深い処理）|新しい単語を語源・イメージ・似た語・自分の経験と結びつける|深く処理するため長期記憶に残りやすい|

- 背景理論は**処理水準説（levels of processing）**（クレイク & ロックハート, Craik & Lockhart）。情報を浅く処理する（音・形だけ）より、深く処理する（意味づけ・関連づけ）ほうが記憶に残りやすいという考え。精緻化リハーサルはこの「深い処理」にあたる。
- 語呂合わせ、イメージとの結びつけ、既習語とのグループ化などは精緻化リハーサルの具体例で、項目17の**記憶ストラテジー**と直接つながる。単純な反復（維持リハーサル）よりも意味づけ・関連づけ（精緻化リハーサル）のほうが効果的。

## 言語学習との関わり

- **エピソード記憶の活用**：単語や表現を自分の経験・場面と結びつけて覚えると記憶に残りやすい。
- **宣言的 → 手続き的**：文法規則を「知っている」（宣言的）段階から、実際に「すらすら使える」（手続き的・自動化）段階へ進むことが、言語運用の上達につながる。
- **作動記憶と技能**：聞き取り・読解では、前の内容を作動記憶に保持しながら次の情報を処理して意味をつなげる。作動記憶の容量はリスニングや読解のしやすさに影響するとされる。
- **チャンク化**：ばらばらの情報を意味のまとまり（チャンク）にすると、限られた短期記憶でも多くを扱える。

## まぎらわしい区別

- **短期記憶** ↔ **作動記憶**：保持だけ（短期記憶）か、保持しながら処理まで行う（作動記憶）か。
- **エピソード記憶** ↔ **意味記憶**：自分が経験した出来事（エピソード）か、体験と切り離された一般的知識（意味）か。
  - 例：「その単語を習った授業の情景を覚えている」＝エピソード記憶／「その単語の意味を知っている」＝意味記憶。
- **宣言的記憶** ↔ **手続き記憶**：ことばで説明できる知識（宣言的）か、体で覚えた技能（手続き的）か。
- **保持時間の層** ↔ **内容の分類**：感覚・短期／作動・長期は「どれくらい保持するか」の分類。エピソード・意味・手続きは「長期記憶の中身」の分類で、別の切り口である点に注意。
- **維持リハーサル** ↔ **精緻化リハーサル**：ただ繰り返す（維持・浅い処理）か、意味づけ・関連づけをする（精緻化・深い処理）か。長期記憶に残りやすいのは精緻化リハーサル。

## キーワードと人名

- **バドリー（Baddeley）**：作動記憶（ワーキングメモリ）のモデル。
- **ミラー（Miller）**：マジカルナンバー**7±2**（短期記憶の容量）。
- **チャンク化（chunking）**：情報を意味のまとまりにまとめて覚えやすくする。
- **リハーサル**：情報を反復して保持・長期化する働き。**維持リハーサル**（ただ繰り返す・浅い処理）と**精緻化リハーサル**（意味づけ・関連づけ・深い処理）に分かれる。
- **処理水準説（クレイク & ロックハート）**：深く（意味的に）処理した情報ほど記憶に残りやすいという考え。精緻化リハーサルの背景理論。
